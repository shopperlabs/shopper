# Shopper Framework

The admin panel of [Shopper](https://laravelshopper.dev), built on Filament and Livewire. It
manages the catalog, customers, orders, payments, shipments, discounts, inventory and settings
of the store, and requires `shopper/core`, `shopper/cart`, `shopper/payment` and `shopper/shipping`.

```bash
composer require shopper/framework
php artisan shopper:install
```

Read the [installation guide](https://docs.laravelshopper.dev) to set up a store.
