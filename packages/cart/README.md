# Shopper Cart

The cart of [Shopper](https://laravelshopper.dev). A cart holds the items a customer intends
to purchase, the addresses and shipping option chosen, and the coupon applied. Its totals are
computed by a pipeline (lines, discounts, taxes) so every read returns amounts ready to charge.

This package is installed with [`shopper/framework`](https://github.com/shopperlabs/shopper).
It is not meant to be required on its own.

Read the [documentation](https://docs.laravelshopper.dev) to learn how Shopper works.
